# Freddy 投資課內容：Beta／Alpha 學習實作

## 課程標示

- 課程歸屬標籤：**Freddy 投資課內容**（依使用者指定）。
- 本工具依據使用者提供的市場 Beta、Alpha 迴歸截距及因子／風格概念製作。
- 本 repo 收錄工具程式、使用說明與驗證資料；課程名稱標示用於交代學習脈絡，不代表完整課程教材或官方發布。
- 未提供的課程正式名稱、講次、出版連結與授權條款不另行推定。

## 本工具對應的課程概念

1. **市場 Beta**：以個股／ETF 的同期歷史報酬對市場基準做含截距迴歸，斜率代表市場敏感度。
2. **模型截距**：顯示每期截距，並明列基準、無風險利率與價格口徑；不直接將估計截距解讀為投資能力。
3. **因子／風格**：屬課程後續脈絡，目前工具只估計單一市場基準的 Beta，未實作 QMV 或多因子歸因。

## 工具資料來源

歷史行情使用 Yahoo Finance chart；預設個股／ETF 收盤價對加權價格指數（^TWII），另有調整價對0050 ETF代理模式。詳細計算方法與限制以 README.md 為準。
