# 台股 Beta 研究室｜Freddy 投資課內容

**課程歸屬標籤：Freddy 投資課內容。**

本 repo 是依使用者提供的 Freddy 投資課 Beta／Alpha 說明製作的學習實作，將「Beta 是迴歸線斜率、Alpha 是模型截距」轉為可操作的台股個股與 ETF 查詢工具。課程脈絡與標示範圍見 [課程說明](docs/course-context.md)。行情另取自 Yahoo Finance。

查詢上市／上櫃個股與 ETF 相對台股市場的歷史 Beta。本機網頁工具，Python 3.12+ 標準函式庫，不需 API 金鑰或安裝套件。

## 啟動

雙擊 `start.cmd` 啟動並自動開啟瀏覽器。也可在此目錄執行 `python server.py`，開啟 http://127.0.0.1:8765 ，或 PowerShell 執行 `./start.ps1`。Ctrl+C 停止服務。請勿從檔案總管直接開啟 index.html，計算需要本機後端。

## 操作

輸入最多八檔代號，例如 `2330, 0050, 00878, 6488.TWO`，選擇日期、日／週／月頻率與比較口徑，按計算。未指定尾碼先查 .TW，來源回報查無時再查 .TWO；可指定尾碼避免歧義。可切換各檔散點圖，下載每期報酬與統計結果 CSV。

## Beta 與 R² 怎麼看

**Beta 看「對基準有多敏感」，R² 看「這段期間的漲跌，有多少能被基準的線性變動解釋」。** 兩者要一起看。預設基準為台股大盤；含息模式則為0050 ETF代理。

散點圖橫軸是基準超額報酬，縱軸是標的超額報酬。模型為：

`標的超額報酬 = 截距 + Beta × 基準超額報酬 + 殘差`

### Beta：迴歸線的斜率

Beta = 1.2，表示基準超額報酬每增加 **1個百分點**，模型估計標的超額報酬平均增加 **1.2個百分點**。這是迴歸線上的平均關係，每期實際報酬仍受到殘差影響，不是固定漲跌倍數。線越陡，Beta絕對值越大。

| Beta | 解讀 |
| --- | --- |
| 1.0 | 對基準變動的敏感度約為一倍。 |
| 1.5 | 對基準較敏感，平均反應幅度較大。 |
| 0.5 | 對基準較不敏感，平均反應幅度較小。 |
| 接近0 | 與基準的線性連動很弱。 |
| 負值 | 在這段樣本中，傾向與基準反向變動。 |

**低Beta不代表股票本身波動小。** 公司消息可能讓股票大漲大跌，卻跟大盤沒有明顯關係，因此Beta很低。

### R²：迴歸模型的解釋力

R² = 80%，表示在所選期間與報酬頻率下，標的報酬的樣本變異約有80%能被這個基準迴歸模型解釋，剩下約20%是模型未解釋的變異。散點越貼近迴歸線，R²越高。

它不代表「80%的日子跟基準同方向」，也不代表「未來預測有80%準確率」。R²本身不顯示方向；方向看Beta或相關係數。

### 兩者一起判讀

| 組合 | 意義 |
| --- | --- |
| 高Beta、高R² | 對基準敏感，且與基準的線性關係明顯。 |
| 低Beta、高R² | 與基準關係明顯，但平均反應幅度較小。 |
| 高Beta、低R² | 估計上對基準敏感，但實際報酬常偏離迴歸線，還有很多其他影響。 |
| 低Beta、低R² | 基準對它的解釋力弱，仍可能有很大的個別風險。 |

「高／低」是概念比較，工具未設定固定分類門檻；負Beta的方向需另行判讀。更換期間、日／週／月頻率或比較基準，Beta與R²都可能改變。多檔比較也應一併確認有效期間與樣本數。

工具在查詢前後都顯示上述判讀說明，可展開數值與組合對照；計算結果旁保留所選標的的Beta敏感度解讀。

## 計算合約

- 簡單報酬 `P_t / P_(t-1) - 1`；含截距 OLS，`y = intercept + beta*x + residual`。
- `x = benchmark_return - rf_period`，`y = stock_return - rf_period`。
- `beta = sum((x-mean(x))*(y-mean(y))) / sum((x-mean(x))²)`。
- 年利率由使用者輸入，預設 0%；每期利率 `(1+annual_rf)^(1/k)-1`，日 k=252、週52、月12。這是固定利率近似，並非歷史逐期無風險利率序列。
- 週／月取各來源最後有效收盤，雙方當期與前期端點日期均須一致。週／月缺期不串接為一期。日報酬的前一觀測日須相同；不填補缺價。
- 只保留起訖端點都在查詢範圍的報酬；排除台北當日行情、當前週／月及查詢終點未完成的週／月。週以星期一至日為界，星期日後才視為完成；月底後才納入該月。
- 最少12筆；少於30筆提示。R² 無標的變異時顯示0；基準無變異則拒絕估計。
- 標準誤為傳統 OLS `sqrt(SSE/(n-2)/Sxx)`，未作異質變異／自相關修正，不顯示誤導性的顯著性結論。
- 多檔各自計算共同有效期間，未強制統一多檔樣本，表格與CSV均列出有效起訖與筆數。

## 來源與口徑

行情讀取 Yahoo Finance chart API，成功回應記憶體暫存1小時，失敗不快取；屬非保證供應的公開端點，可能限流、缺檔或改版。網路失敗會顯示錯誤，沒有假資料或靜默替代。

- 預設：Yahoo close 對 `^TWII` 加權價格指數，不含現金股利再投資；企業行動調整依供應商定義。
- 含息模式：Yahoo adjclose 對 `0050.TW` adjclose。0050 是大型股ETF代理，不是全市場報酬指數；若缺調整價直接報錯。
- 本工具截距一律標示每期截距，不把預設0利率或價格指數模型的剩餘直接稱為已證實的 Jensen Alpha。
- 證交所明確區分價格指數與報酬指數：[加權指數編製要點](https://www.twse.com.tw/downloads/zh/products/indices/IndexS02.pdf)。

僅本機綁定127.0.0.1，沒有交易、推播、帳密或外部程式依賴。不是全市場批次篩選器；指定代號即時計算，不建立全市場行情庫。
